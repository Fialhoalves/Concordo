A sala do grupo roda no PC de um amigo.

O Concordo é um chat estilo Discord para o seu grupo de amigos no Windows. Um de vocês hospeda, os outros entram por um código de convite. Sem conta, sem servidor pago, sem anúncios.

Baixar para Windows Ver no GitHub

Grátis e de código aberto. Só para Windows por enquanto. O instalador não é assinado, então o Windows pode mostrar um aviso na primeira vez (veja como seguir).

Três passos e vocês estão conversando

Não tem cadastro nem site para abrir. O app faz o trabalho de servidor no computador de quem hospeda.

  1. Instale

    Baixe o instalador na página de versões do GitHub e execute. As atualizações depois chegam sozinhas.

  2. Hospede ou entre com um convite

    Quem hospeda: clique em Hospedar, dê um nome à sala e gere um convite. Quem entra: clique em Entrar, cole o código e escolha um apelido.

  3. Converse

    Escreva nos canais, abra uma chamada de voz, ligue a câmera ou compartilhe a tela. Quem hospeda só precisa deixar o app aberto.

O que dá para fazer na sala

O que você espera de um chat de grupo, rodando entre vocês.

Conversar

Canais de texto para cada assunto.

  • Canais de texto para separar o papo, os jogos e as fotos.
  • Formatação, reações e enquetes para decidir o horário sem confusão.
  • Confirmação de leitura para saber quem já viu.
  • Mensagens assinadas: dá para conferir que foi mesmo aquela pessoa que escreveu.
  • Mensagens diretas com criptografia de ponta a ponta.

Falar e ver

Voz, vídeo e tela direto entre os amigos.

  • Voz, vídeo e compartilhamento de tela por WebRTC, sem passar por servidor de terceiros.
  • Zoom na tela compartilhada para ler o que está pequeno.
  • Soundboard com os sons da sala, para as piadas internas.

Organizar a sala

Cada um no seu lugar.

  • Papéis: dono, moderador e membro.
  • Convites por código para entrar sem criar conta.

Manter a sala de pé

Para quando o PC do host precisa descansar.

  • Troca automática de host: se quem hospeda sumir, outro amigo assume a sala.
  • Atualização automática: o app baixa a versão nova e avisa para reiniciar.
  • Grátis e de código aberto: o código está no GitHub para quem quiser ler.

Quem vê o quê

Não tem empresa guardando suas conversas, mas isso não quer dizer que ninguém vê nada. Veja com clareza onde ficam as coisas.

Quem hospeda
As mensagens dos canais e os arquivos ficam no computador do host, então ele consegue vê-los. Ele também enxerga os metadados: quem entrou, quando, e quem trocou mensagem direta com quem. Hospede e escolha host entre pessoas de confiança.
Mensagens diretas
Só quem conversa consegue ler. O conteúdo é cifrado de ponta a ponta e o host apenas repassa o texto cifrado.
Mensagens e votos
As mensagens dos canais são assinadas, o que ajuda a provar a autoria. Os votos das enquetes não são assinados.
Voz, vídeo e tela
Vão direto de um amigo para o outro. Em compensação, o endereço IP de cada pessoa fica visível para os outros da chamada.
No caminho
Para a sala ser alcançada de fora de casa, o app usa um túnel gratuito da Cloudflare, sem conta. O tráfego da sala passa por ele.

O Concordo foi feito para grupos pequenos de amigos de confiança. Não o use para segredos de alto risco.

Perguntas frequentes

O Windows avisou que o app é desconhecido. É seguro?

O instalador não é assinado digitalmente, então o Windows SmartScreen mostra o aviso na primeira instalação. Isso não prova nada sobre o app, mas também é motivo para baixar só desta página ou do repositório oficial.

Para seguir, clique em Mais informações e depois em Executar assim mesmo. As atualizações seguintes não pedem isso de novo. O código é aberto, então você pode ler o que o app faz.

Quanto custa?

Nada. O Concordo é grátis e de código aberto, não tem anúncios e não precisa de conta. Como a sala roda no PC de um amigo, também não existe servidor para pagar.

Quantos amigos cabem na sala?

O Concordo é pensado para grupos pequenos. Nas chamadas de voz, vídeo e tela, cada pessoa envia para as outras diretamente, então o conforto cai conforme o grupo cresce: o limite é de 8 pessoas por canal de voz, mas o uso confortável é de 4 a 5, principalmente se alguém compartilha a tela.

O que acontece se o host fechar o app?

Se o app do host fechar ou o PC dele desligar, a sala fica fora do ar até alguém reabri-la. Por isso o host precisa deixar o Concordo aberto enquanto o grupo conversa.

Se ele sumir, outro amigo que tem uma cópia da sala pode assumir como novo host. O histórico fica com quem guardou a cópia, e mensagens dos últimos instantes antes da queda podem se perder. Dá para passar a sala para outro amigo antes de sair.

Funciona em Mac, Linux ou celular?

Não. Por enquanto o Concordo é só para Windows.
